# Greek Evaluator Knockout

This directory is generated by `python -m genseki.tournament`. It is a
resumable, deterministic single-elimination tournament for the 18 retained
Greek neural evaluators. Two play-in matches produce a 16-bot bracket. Standard
matches use 20 mirrored games; the final uses 40. Ties receive fresh 10-game
mirrored batches. After a demonstrated non-termination failure, the protocol
was amended to cap this at two tiebreak batches and advance the higher frozen
seed if all 40 games remain tied. See `protocol-amendments.json`; such an
advancement is administrative, not a game victory.

The semifinals use the deliberately accelerated format of 10 mirrored games
with a strict 125 ms response deadline. See `protocol-amendments.json`.

The winner plays exactly two 500 ms games against the attributed MIT Alpha
backend, once as White and once as Black. Timeout results remain valid because
they would be funny. `Rho/` is not read, written, imported, or executed by
this tournament.

Tournament lore is rendered alongside the auditable results. In particular,
Sigma's administrative semifinal advancement is canonically attributed to a
metal chair supplied by the spectators.
