# Security Policy

we don't want to leak your personal data for malicious intent. Genseki is only a Hive bot.

## Supported Versions

Only the latest versions will be updated with security changes. Once a version is pushed, we cannot retract/edit it. That's common sense 😭.

## Reporting a Vulnerability

There are 2 ways that I support of reporting a security vulnerability. Those are:

A) Opening an issue on github. [Create an Issue here](https://github.com/SahilKDas/Genseki/issues/new)

B) DM-ing me on **DISCORD**, my username is **lordhank2**. Do not confuse it with a handlebar.
